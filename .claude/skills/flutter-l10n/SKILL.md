# Локализация

## Где что лежит

```
lib/l10n/app_en.arb        # шаблон, из него генерируются геттеры
lib/l10n/app_ru.arb
lib/l10n/generated/        # сгенерированное, руками не трогать
l10n.yaml                  # конфиг codegen
```

## Порядок

1. Ключ добавляется **сразу во все ARB-файлы**, не только в шаблон. Пропущенный ключ в
   неосновной локали молча подставит английский текст, и это заметит только пользователь.
2. Имя ключа — `<экран><Что>`: `homeRecentActivity`, `authSignUpPasswordHelper`.
3. Описание (`@ключ`) в шаблонном файле — для плюралей и подстановок обязательно.
4. Сгенерировать и проверить:

```bash
flutter gen-l10n && flutter analyze --no-pub
```

5. В коде — только через `AppLocalizations.of(context)`, никакого хардкода.

## Подстановки и плюрали

```json
{
  "homeVolumeToday": "Вы подняли {kg} кг сегодня",
  "@homeVolumeToday": {
    "placeholders": { "kg": { "type": "String" } }
  },

  "workoutExerciseCount": "{count, plural, =1{1 упражнение} few{{count} упражнения} other{{count} упражнений}}",
  "@workoutExerciseCount": {
    "placeholders": { "count": { "type": "int" } }
  }
}
```

- У русского три формы вместо двух: нужны `one`/`few`/`many`/`other`, а не только
  `=1` и `other`. Проверять на 1, 2, 5 и 21.
- Числа и даты внутри строки не склеивать вручную — передавать плейсхолдером.

## Даты и время

```dart
DateFormat.jm(l10n.localeName).format(date);        // 21:40 на ru/kk, 9:40 PM на en
DateFormat('d MMM', l10n.localeName).format(date);  // 8 окт
```

Руками собранное время («9:40 PM» для всех локалей) — дефект: русская локаль
24-часовая, английская с AM/PM.

## Проверка вёрстки

Самая длинная локаль ломает разметку первой — здесь русский: он в среднем
на 15–20% длиннее английского, а составные слова не переносятся.

- Узкая подпись под цифрой → `FittedBox`, иначе «ДЛИТЕЛ…».
- Ряд из равных слотов (дни недели, сегменты) → `Expanded` на слот, зазор **между**
  слотами, а не padding внутри каждого: иначе последний слот шире остальных.
- Кнопки и бейджи с текстом переменной длины проверять на всех локалях, в обеих темах.

## Что считается дефектом локализации

- Строка, видимая пользователю, собрана в коде (включая сообщения об ошибках из датасорсов).
- Фильтр или выбор хранится как **локализованная строка**: пользователь меняет язык —
  сопоставление перестаёт срабатывать. Хранить enum, переводить только при отрисовке.
- Поиск сравнивает запрос только с английским названием — искать и по переведённому.
- Язык приложения жёстко `en` при первом запуске вместо языка устройства.
