# Готовность к сторам

Проверять **до** того, как собирать релиз: половина пунктов требует решений
(домен, тексты политики, аккаунты), а не кода.

## Блокеры — без них не примут

```bash
grep -rn "com.example" android/app/build.gradle* ios/Runner.xcodeproj/project.pbxproj
grep -rn "signingConfigs\|signingConfig " android/app/build.gradle*
ls ios/Runner/Assets.xcassets/AppIcon.appiconset/ android/app/src/main/res/mipmap-*/
grep -rn "ITSAppUsesNonExemptEncryption" ios/Runner/Info.plist
grep -rn "SCHEDULE_EXACT_ALARM\|USE_EXACT_ALARM" android/app/src/main/AndroidManifest.xml
```

| # | Пункт | Что требуется |
|---|---|---|
| 1 | **Bundle id / applicationId** | свой обратный домен, одинаковый в iOS и Android. `com.example.*` не принимают, а поменять после первой публикации нельзя |
| 2 | **Подпись Android** | релизный keystore, `key.properties` вне git, `signingConfig signingConfigs.release`. Релиз с debug-ключом Play отвергает |
| 3 | **Иконка** | свои иконки всех размеров вместо дефолтной флаттеровской; `flutter_launcher_icons` делает оба набора |
| 4 | **Удаление аккаунта** | требование и Apple, и Google для приложений с регистрацией: экран в приложении **и** веб-страница с инструкцией. Реализуется Edge Function с `service_role` |
| 5 | **Privacy Policy и Terms** | тексты, публичные URL, ссылки из приложения и из листинга стора |
| 6 | **`ITSAppUsesNonExemptEncryption`** | `false` в `Info.plist`, иначе каждая сборка висит на вопросе про экспорт шифрования |
| 7 | **Экраны-заглушки** | «Coming soon» — отказ по гайдлайнам Apple. Либо реализовать, либо убрать из навигации |
| 8 | **Точные будильники (Android)** | `SCHEDULE_EXACT_ALARM` требует обоснования. Напоминания работают на неточных (`inexact`) — оставить точные только если без них функция не работает |
| 9 | **Имя и ориентация** | имя приложения без подчёркиваний и технических суффиксов; landscape отключить, если макетов под него нет |

## Анкеты

- **App Privacy (Apple)** и **Data Safety (Google)** — перечислить, что собирается
  (почта, имя, фото, переписка, платежи), зачем и передаётся ли третьим лицам.
  Анкета должна совпадать с тем, что приложение делает на самом деле.
- Возрастной рейтинг, категория, ключевые слова, описание.
- Скриншоты: по размерам устройств Apple и Google, **на каждом языке приложения**.
- Приложение с социальными функциями — отдельно: механика жалоб и блокировки
  пользователей, модерация пользовательского контента. Apple отклоняет без них.

## Безопасность сборки

```bash
grep -rn "baseUrl\|apiKey\|token\|secret" lib | grep -v "dart-define"
```

- `baseUrl` и ключи — через `--dart-define`, а не литералами в коде.
- Серверные секреты в приложении не появляются никогда: всё, что попало в сборку,
  извлекается из неё за минуты.
- Токены — в secure storage, не в `SharedPreferences`.
- Проверить, что логирование в релизе не пишет персональные данные.

## Перед отправкой

```bash
flutter analyze --no-pub && flutter test
flutter build appbundle --release
flutter build ipa --release
```

- Поставить релизную сборку на чистое устройство: пройти регистрацию, онбординг,
  основной сценарий, разрешения на уведомления и фото, выход и повторный вход.
- Проверить на самой длинной локали и на маленьком экране.
- Номер версии и build number подняты.

## Порядок, в котором дешевле делать

1. Bundle id и keystore — пока нет ни одной публикации, это бесплатно.
2. Иконка и имя.
3. Удаление аккаунта (единственный пункт с реальным кодом).
4. Privacy Policy, Terms, страница удаления аккаунта — три страницы, можно на GitHub Pages.
5. Флаги `Info.plist`, разрешения, ориентация.
6. Решение по заглушкам.
7. Анкеты, скриншоты, описания.
