# Аудит на соответствие правилам

## Быстрый прогон по всей кодовой базе

```bash
echo "=== setState (запрещён) ==="
grep -rn "setState" lib || echo "нет"

echo "=== приватные виджет-классы (должны быть только State) ==="
grep -rn "^class _.*extends Stateless\|^class _.*extends Stateful" lib || echo "нет"

echo "=== методы, возвращающие виджеты ==="
grep -rn "  Widget _[a-zA-Z]*(" lib || echo "нет"

echo "=== emit после await без isClosed ==="
grep -rn -A6 "await " lib --include="*_cubit.dart" | grep -B1 "emit(" | grep -v isClosed | head -30

echo "=== хардкод цветов в виджетах ==="
grep -rn "Color(0x" lib/features | grep -v "/theme/" || echo "нет"

echo "=== raw ScaffoldMessenger вместо AppSnackBar ==="
grep -rn "ScaffoldMessenger" lib | grep -v app_snack_bar.dart || echo "нет"

echo "=== withOpacity (deprecated) ==="
grep -rn "withOpacity(" lib || echo "нет"

echo "=== хардкод пользовательских строк ==="
grep -rn "Text('" lib/features | grep -v "l10n\." | head -20
```

Не всё найденное — дефект: строки вроде `Text('·')`, `Text('${a}/${b}')` и имена из данных
легальны. Отделять пользовательский текст от разметки.

## Аудит одного экрана

Пройти по списку, для каждого пункта — конкретная строка файла или «чисто».

1. **`setState`** → `ValueNotifier` + `ValueListenableBuilder`.
2. **Приватные виджет-классы** → отдельные файлы, публичные имена (скилл `flutter-widget`).
3. **Методы `Widget _buildXxx()`** → отдельные виджеты. Метод перестраивается вместе
   с родителем, не бывает `const` и прячет размер экрана.
4. **`dispose()`** — для каждого `ValueNotifier`, `TextEditingController`,
   `AnimationController`, `Timer`, подписки. Контроллер, отданный в `showDialog`,
   диспозит сам диалог, а не вызывающая сторона.
5. **Ключи в списках** — `ValueKey(<id>)` там, где элементы можно удалять и
   переставлять. Без ключа удаление оставляет состояние удалённого в соседней карточке.
6. **`listener`** — switch-выражение через `=>`, деструктуризация в паттерне,
   `_ => null` в конце, `AppSnackBar` вместо `ScaffoldMessenger`.
7. **`buildWhen`** там, где стейт тикает чаще, чем нужно картинке.
8. **Тяжёлые вычисления в `build`** — считать при загрузке в кубите или в `late final`.
   Значения, меняющиеся по времени, — в самотикающем виджете, а не в `build` родителя.
9. **Цвета** — `context.themeExt`, не `AppColors` напрямую для поверхностей
   и не литералы. Проверить обе темы.
10. **Строки** — `AppLocalizations`, все локали, плюрали через ICU, даты через
    `DateFormat(..., l10n.localeName)`.
11. **Переполнения** — проверить самую длинную локаль; узкие подписи в `FittedBox`,
    ряды равных слотов через `Expanded` с зазором **между** слотами.
12. **Сырой текст исключения** в снекбаре или на экране — заменить локализованным,
    исходное — в `AppLogger`.
13. **Размер файла** — экран больше ~250 строк почти всегда означает, что в нём живут
    виджеты, которым пора в свои файлы.

## После правок

```bash
flutter analyze --no-pub
flutter test
git diff -w --stat     # проверить, что в диффе нет переформатирования нетронутого кода
```

`dart format` на весь файл не запускать: шум прячет смысловые правки.

## Отчёт

Коротко и по делу: что нашёл, что исправил, что осознанно оставил и почему. Найденное,
но не исправленное, записать в `docs/BUGS.md` — иначе потеряется.
