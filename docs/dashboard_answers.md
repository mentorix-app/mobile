## Что видно в редакторе программ (проверено вручную)
- Шаг 1 «General»: название и описание на английском и русском, категория, сложность, ссылка на превью.
- Категории: Weight loss, Muscle gain, Rehabilitation, Endurance, Functional.
- Сложность: Beginner, Intermediate, Advanced, Expert.
- Шаг 2 «Structure»: недели → в неделе 7 дней → в дне упражнения. Упражнения можно сгруппировать в блок.
- Упражнения без группы стоят по отдельности, у них нет типа блока. Как они приходят в клиентском API — сверить по живому JSON.
- Типы блоков: EMOM, AMRAP, For Time, Intervals, Chipper, Ladder, Death By, Superset, Complex, Skill Work, Strength, Conditioning, Gymnastics, Weightlifting. По умолчанию при группировке — Complex. Названия только на английском — в приложении нужен перевод.
- У блока есть своя инструкция и настройка «видимость только для выбранных клиентов». Клиент получает только разрешённые ему блоки.
- У упражнения поля Sets, Reps и Instruction.
- Поле Reps режет буквы: «15 cal» сохраняется как «15». Единицы вроде калорий тренер пишет в instruction.
- Sets может быть пустым (у AMRAP оставлено пустым — проверить sets: null).
- Упражнения берутся из библиотеки тренера, картинок у них в клиентском API нет.
