## Этап 1. Каркас

### Что сделано

- Токены `globals.css` перенесены в код один раз, HEX в виджетах не пишется:
  - `lib/core/theme/app_colors.dart` — тёмная палитра (`.dark`);
  - `lib/core/theme/app_light_colors.dart` — светлая (`:root`);
  - `lib/core/theme/app_theme_extension.dart` — `ThemeExtension` с токенами для виджетов
    и `context.themeExt`;
  - `lib/core/theme/app_radii.dart`, `app_spacing.dart` — радиусы и отступы.
- Текстовая шкала на Inter через `google_fonts` — `lib/core/theme/app_text_theme.dart`.
- Светлая и тёмная `ThemeData` — `lib/core/theme/app_theme.dart`.
- DI на `get_it` — `lib/core/di/service_locator.dart`.
- Роутинг на `go_router` — `lib/core/router/`.
- `MaterialApp.router` — `lib/app.dart`, точка входа — `lib/main.dart`.
- Экран-заглушка `HomeScreen` с логотипом, чтобы было что проверять глазами.
- Шаблонный счётчик и его тест заменены тестами токенов и смоук-тестом.

### Решения

| Вопрос | Решение |
|---|---|
| `destructive` | HEX из `globals.css` (Tailwind v4): `#E7000B` / `#FF6467`. В `CLAUDE.md` стояли значения v3 (`#DC2626` / `#F87171`) — таблица исправлена |
| `sidebar-primary` в тёмной теме | `#1447E6`, синий: палитра не полностью ахроматическая — формулировка в `CLAUDE.md` исправлена |
| Нейминг палитр | `AppColors` — тёмная, `AppLightColors` — светлая |
| `AppSpacing` | три токена из `globals.css` (9 / 8 / 56) и шкала 4 / 8 / 12 / 16 / 24 уровня приложения — её в `globals.css` нет, согласовать с дизайнерами |
| Начертания | в `globals.css` только размеры: h1–h5 — `w600`, остальное — `w400` |
| `onError` | в `globals.css` нет `destructive-foreground`: берётся `primary-foreground`, контраст ≥ 4.5:1 проверен тестом |
| Слоты `TextTheme` вне шкалы | `display*`, `titleSmall`, `labelLarge`, `labelMedium` остаются Material-умолчаниями (кнопки используют `labelLarge` 14) |
| `sidebar-*` | есть в `AppColors`/`AppLightColors`, в `AppThemeExtension` не заведены до планшетной раскладки |
| Тема | `ThemeCubit` (`Cubit<ThemeMode>`), по умолчанию — системная; выбор хранится в `shared_preferences`, ключ `theme_mode`, значения `system` / `light` / `dark` |
| Язык | локаль системная, переключение — этап 2 |
| `GoRouter` | регистрируется в `get_it`, в `MentorixApp` передаётся параметром: `GetIt` вызывается только в `main()`, тесты подставляют свой роутер |
| Экран 404 | не заводился, до этапа 4 показывается стандартная страница `go_router` |

### Сценарии проверки

Запускать на **полностью перезапущенном** приложении (`flutter run`, не hot reload).

1. **Светлая тема.** Системная тема — светлая. Экран белый, по центру полный логотип
   с тёмной надписью «Mentorix».
2. **Тёмная тема.** Переключить системную тему на тёмную (приложение может быть открыто).
   Фон почти чёрный (`#0A0A0A`), логотип со светлой надписью.
3. **Надпись в логотипе.** В SVG надпись — элемент `<text>` с `font-family: Inter`.
   Проверить, что она отрисовалась и выглядит как Inter. Если шрифт подменился на
   системный — это находка, записать в `BUGS.md`; решение — попросить у дизайнеров
   логотип с надписью, переведённой в контуры.
4. **Языки.** Системный язык русский → английский → любой другой (например, немецкий):
   приложение запускается без ошибок. Для неподдерживаемого языка берётся английский
   (первая из `supportedLocales`).
5. **Название в переключателе задач** — «Mentorix» в обоих языках.
6. **Первый запуск без сети** (удалить приложение, выключить интернет, запустить):
   приложение стартует, текст может быть системным шрифтом — Inter скачивается при
   первом использовании и дальше кешируется.

### На что обратить внимание

- В тестах `google_fonts` не может скачать Inter (в тестовом окружении сети нет) и
  печатает две строки `Failed to load font` — это ожидаемо, тесты от этого не падают.
  Если шум начнёт мешать, шрифт можно положить в `assets/` и отключить рантайм-загрузку.
- Файлы в `.claude/` в `.gitignore`, поэтому правки `CLAUDE.md` в коммит не попадут.

### Правки по итогам проверки (2026-10-11)

Записаны в `BUGS.md` до исправления, исправлены в этом же этапе:

- **№ 1 ✅** — `ThemeCubit` вместо фиксированного `ThemeMode.system`. Часть бывшего
  этапа 2, вынесена вперёд; язык остаётся в этапе 2.
- **№ 2 ✅** — пути к `assets/icons/*.svg` берутся из `Assets`
  (`lib/generated/assets.dart`, создан расширением «Flutter Assets Generator Pro»).
- **№ 3** — снят пользователем.

Решения по этим правкам:

| Вопрос | Решение |
|---|---|
| `lib/generated/` в `.gitignore` | **не добавлять.** Расширение работает только в IDE: на чистом клоне, в CI и у коллеги без расширения файла не будет, и проект не соберётся. Файл маленький и меняется только при добавлении картинок. То же с `lib/l10n/generated/` |
| Состояние темы | `Cubit<ThemeMode>` без отдельного класса состояния: у темы одно значение |
| Чтение выбора | синхронное, из уже загруженных `SharedPreferences` — первый кадр сразу в нужной теме, без мигания |
| Слои | `ThemeRepository` (domain) → `ThemeRepositoryImpl` (data) → `ThemeCubit`. Отдельного datasource нет: `SharedPreferences` и есть источник |
| Переключатель | временная `ThemeModeButton` в `AppBar` стартового экрана: система → светлая → тёмная → система. Уйдёт на экран настроек (этап 2) |
| Подпись кнопки | tooltip с названием текущего режима, строки в обоих ARB |

Сценарии проверки (в дополнение к списку выше, на полностью перезапущенном приложении):

7. **Переключатель.** Кнопка справа в `AppBar`. Три нажатия: иконка и подсказка
   меняются система → светлая → тёмная → система, экран перекрашивается сразу.
8. **Выбор переживает перезапуск.** Выбрать «тёмная» при светлой системной теме,
   убить приложение, запустить снова — сразу тёмная, без вспышки светлой.
9. **«Системная» подхватывает систему.** Выбрать «системная», сменить тему в настройках
   телефона — приложение следует за ней.
10. **Подсказка на языках.** Долгое нажатие на кнопку: на русском «Системная тема» /
    «Светлая тема» / «Тёмная тема», на английском — «System theme» / «Light theme» /
    «Dark theme».
11. **Логотип в светлой и тёмной теме** по-прежнему подбирается по теме (теперь через
    константы `Assets`).
